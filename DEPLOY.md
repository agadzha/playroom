# Publish Playroom and share it with friends

Playroom is a Node.js, Express, and Socket.IO web app. The website and online Tic-Tac-Toe server must run together on a host that supports WebSockets and persistent storage. A static-only host is not enough.

## Repository

This project is prepared for https://github.com/agadzha/playroom. The page source is Brotli-compressed and split into text parts in public/page-data; server.js joins and decompresses it at request time. Do not delete or reorder these part files.

## Deploy on Render

1. Sign in at https://dashboard.render.com/.
2. Choose New → Blueprint (the exact label can vary).
3. Connect GitHub and select the agadzha/playroom repository.
4. Render reads render.yaml. It configures a Starter web service and a 1 GB persistent disk.
5. Review the current service and disk pricing shown in your Render account before applying. Do not confirm billing unless you accept the cost.
6. After deployment finishes, open the generated HTTPS URL and visit /healthz. It should return JSON with "ok": true.
7. Test the main page. Register two test accounts in separate browsers/devices, create an online Tic-Tac-Toe room, copy the invite link, and join from the second account/device.

## Share the link

Send friends the public HTTPS address generated by Render. For online Tic-Tac-Toe, create a room in the Online tab and share its invitation link. Both players need accounts on the same deployed site.

## Safety and limitations

- Never commit data.json, .env, secrets, or node_modules. The .gitignore file excludes these local files.
- Use a unique password. The app does not yet provide email verification, password reset, or a moderation dashboard.
- Only Tic-Tac-Toe is multiplayer; the other games run locally in each browser.
- Accounts and stats use a JSON file on the persistent disk. This is suitable for a small friend group, not high traffic.
- Back up the persistent disk before major server changes.
- Before a large public launch, add a managed database, account recovery/deletion, abuse reporting, monitoring, and automated integration tests.

## Run locally on macOS

1. Install Node.js LTS from https://nodejs.org/.
2. Double-click run.command. If macOS blocks it, right-click and choose Open.
3. Open http://localhost:3000 and keep Terminal running while playing.
